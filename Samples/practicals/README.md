# DEAL.JS practical examples

These examples are larger, adaptable workflows rather than isolated syntax demonstrations. They use DEAL source as the primary implementation language and assume the host has initialized the browser provider and loaded the `deal/web` module.

- [Web scraper](Web-Scraper.djs) — visit a list of pages and collect page titles and headings.
- [Batch website collector](Batch-Website-Collector.djs) — process a URL collection and store structured results.
