# DEAL.JS tutorials

Follow the tutorials in order. Each `.djs` file is DEAL source, with comments explaining the concepts being introduced. Run the files through the DEAL.JS compiler and inspect generated JavaScript only when you want to study the compilation result.

1. [Getting started](01-Getting-Started.djs) — values, collections, iteration, and output.
2. [Browser and Fetch](02-Browser-and-Fetch.djs) — synchronous browser operations and asynchronous Fetch.
3. [Commands](03-Commands.djs) — a compact command and iteration example.
